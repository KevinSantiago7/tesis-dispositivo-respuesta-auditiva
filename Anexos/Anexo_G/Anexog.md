# ANEXO G. EVALUACIÓN DE USABILIDAD Y ACEPTACIÓN TECNOLÓGICA DEL DISPOSITIVO

---

# G.1 Introducción

La evaluación del dispositivo tecnológico incluyó un análisis de interacción usuario-tecnología mediante instrumentos orientados a medir la usabilidad percibida y la aceptación tecnológica del prototipo desarrollado.

Para esta evaluación se aplicaron dos instrumentos:

- **System Usability Scale (SUS):** utilizado para evaluar la percepción general de usabilidad del sistema.
- **Technology Acceptance Model (TAM):** aplicado mediante una adaptación para analizar la percepción de utilidad, facilidad de uso e intención de uso del dispositivo.

Los resultados obtenidos corresponden a una evaluación exploratoria de interacción humano-tecnología y no representan una validación clínica del dispositivo ni una evaluación diagnóstica.

# G.3 Evaluación mediante System Usability Scale (SUS)

## G.3.1 Descripción del instrumento

La **System Usability Scale (SUS)** es un instrumento estandarizado utilizado para evaluar la percepción del usuario respecto a la facilidad de uso, comprensión e interacción con un sistema tecnológico.

El instrumento está compuesto por diez afirmaciones evaluadas mediante una escala tipo Likert de cinco niveles:

| Valor | Interpretación |
|---|---|
| 1 | Totalmente en desacuerdo |
| 2 | En desacuerdo |
| 3 | Neutral |
| 4 | De acuerdo |
| 5 | Totalmente de acuerdo |

---

## G.3.2 Cuestionario SUS aplicado

| Ítem | Afirmación |
|---|---|
| 1 | Creo que me gustaría utilizar este sistema con frecuencia. |
| 2 | Encontré el sistema innecesariamente complejo. |
| 3 | Pensé que el sistema era fácil de utilizar. |
| 4 | Creo que necesitaría apoyo técnico para utilizar este sistema. |
| 5 | Encontré que las diferentes funciones del sistema estaban bien integradas. |
| 6 | Pensé que había demasiada inconsistencia en este sistema. |
| 7 | Creo que la mayoría de las personas aprenderían rápidamente a utilizar este sistema. |
| 8 | Encontré el sistema muy complicado de usar. |
| 9 | Me sentí muy seguro utilizando el sistema. |
| 10 | Necesitaría aprender muchas cosas antes de poder utilizar este sistema. |

---

## G.3.3 Método de cálculo SUS

El puntaje SUS fue calculado mediante el procedimiento establecido para este instrumento:

- Para los ítems impares (1, 3, 5, 7 y 9), se resta 1 a la puntuación obtenida.
- Para los ítems pares (2, 4, 6, 8 y 10), se calcula la diferencia entre 5 y la puntuación obtenida.
- La suma obtenida se multiplica por 2,5.

El resultado final corresponde a una escala entre 0 y 100 puntos.

# G.4 Evaluación de aceptación tecnológica mediante TAM

## G.4.1 Descripción del instrumento

El **Technology Acceptance Model (TAM)** fue utilizado mediante una adaptación para evaluar la percepción de aceptación tecnológica del dispositivo desarrollado.

Las dimensiones consideradas fueron:

- **Utilidad percibida:** percepción del usuario sobre el aporte y valor práctico del dispositivo.
- **Facilidad de uso percibida:** percepción sobre la facilidad de interacción con el sistema.
- **Intención de uso:** disposición del usuario para utilizar o recomendar una herramienta con características similares.

Las respuestas fueron registradas mediante una escala de cinco niveles:

| Valor | Interpretación |
|---|---|
| 1 | Totalmente en desacuerdo |
| 2 | En desacuerdo |
| 3 | Neutral |
| 4 | De acuerdo |
| 5 | Totalmente de acuerdo |

---

## G.4.2 Instrumento TAM aplicado

### Utilidad percibida

| Código | Afirmación |
|---|---|
| UP1 | El dispositivo proporciona información útil para el seguimiento de respuestas observables. |
| UP2 | La plataforma permite consultar información relevante de los ensayos realizados. |
| UP3 | La información presentada puede apoyar la revisión del comportamiento observado. |

---

### Facilidad de uso percibida

| Código | Afirmación |
|---|---|
| FUP1 | La interacción con el dispositivo resulta sencilla. |
| FUP2 | La información presentada en la plataforma es fácil de comprender. |

---

### Intención de uso

| Código | Afirmación |
|---|---|
| IU1 | Utilizaría una herramienta tecnológica de este tipo si estuviera disponible. |
| IU2 | Recomendaría el uso de una herramienta con estas características. |
