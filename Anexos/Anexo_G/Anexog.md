# ANEXO G. EVALUACIÓN DE USABILIDAD Y ACEPTACIÓN TECNOLÓGICA DEL DISPOSITIVO

---

# G.1 Introducción

La evaluación del dispositivo tecnológico incluyó un análisis de interacción usuario-tecnología mediante instrumentos orientados a medir la usabilidad percibida y la aceptación tecnológica del prototipo desarrollado.

Para esta evaluación se emplearon dos instrumentos complementarios:

- **System Usability Scale (SUS):** utilizada para evaluar la percepción general de usabilidad del sistema.
- **Technology Acceptance Model (TAM):** aplicado para analizar la percepción de utilidad, facilidad de uso e intención de uso del dispositivo.

Estas evaluaciones permitieron complementar la validación experimental del prototipo desde la perspectiva de los usuarios que tuvieron interacción con la solución tecnológica.

Los resultados obtenidos corresponden a una valoración exploratoria de interacción humano-tecnología y no representan una validación clínica del dispositivo ni una evaluación diagnóstica.

# G.3 Evaluación mediante System Usability Scale (SUS)

## G.3.1 Descripción del instrumento

La **System Usability Scale (SUS)** es un instrumento estandarizado utilizado para evaluar la percepción del usuario respecto a la facilidad de uso, complejidad, consistencia y confianza frente a un sistema tecnológico.

El instrumento está compuesto por diez afirmaciones evaluadas mediante una escala tipo Likert de cinco niveles:

| Valor | Interpretación |
|---|---|
| 1 | Totalmente en desacuerdo |
| 2 | En desacuerdo |
| 3 | Neutral |
| 4 | De acuerdo |
| 5 | Totalmente de acuerdo |

---

# G.3.2 Cuestionario SUS aplicado

| Ítem | Afirmación |
|---|---|
| 1 | Creo que me gustaría utilizar este sistema con frecuencia. |
| 2 | Encontré el sistema innecesariamente complejo. |
| 3 | Pensé que el sistema era fácil de utilizar. |
| 4 | Creo que necesitaría apoyo técnico para utilizar este sistema. |
| 5 | Encontré que las diferentes funciones del sistema estaban bien integradas. |
| 6 | Pensé que había demasiada inconsistencia en este sistema. |
| 7 | Creo que la mayoría de las personas aprenderían rápidamente a utilizar este sistema. |
| 8 | Encontré el sistema muy complicado de usar. |
| 9 | Me sentí muy seguro utilizando el sistema. |
| 10 | Necesitaría aprender muchas cosas antes de poder utilizar este sistema. |

---

# G.3.3 Método de cálculo SUS

El puntaje SUS fue calculado mediante el procedimiento establecido para este instrumento:

- Para los ítems impares se resta 1 a la puntuación obtenida.
- Para los ítems pares se calcula la diferencia entre 5 y la puntuación obtenida.
- La suma resultante se multiplica por 2,5.

El resultado final se encuentra en una escala entre 0 y 100 puntos.

# G.4 Evaluación de aceptación tecnológica mediante TAM

## G.4.1 Descripción del instrumento

El **Technology Acceptance Model (TAM)** fue utilizado para analizar la percepción de aceptación tecnológica del dispositivo desarrollado.

Este modelo permitió evaluar tres dimensiones principales:

- **Utilidad percibida:** percepción del usuario respecto al valor y aporte de la tecnología.
- **Facilidad de uso percibida:** percepción sobre la facilidad de interacción con el sistema.
- **Intención de uso:** disposición del usuario para utilizar o recomendar una herramienta de características similares.

Las respuestas fueron registradas mediante una escala de cinco niveles:

1 = Totalmente en desacuerdo  
5 = Totalmente de acuerdo

---

## Utilidad percibida

| Código | Afirmación |
|---|---|
| UP1 | El dispositivo proporciona información útil para el seguimiento de respuestas observables. |
| UP2 | La plataforma permite consultar información relevante de los ensayos realizados. |
| UP3 | La información presentada puede apoyar la revisión del comportamiento observado. |

# G.5 Interpretación conjunta SUS-TAM

Los resultados obtenidos mediante SUS y TAM evidencian una percepción favorable respecto al uso del prototipo desarrollado.

La evaluación mediante SUS permitió identificar una valoración positiva de la interacción con el sistema, reflejando que los participantes percibieron el flujo de uso como comprensible y adecuado dentro del contexto experimental.

Por otra parte, los resultados obtenidos mediante TAM muestran una aceptación favorable de la tecnología desarrollada, destacando especialmente la intención de uso y la utilidad percibida del dispositivo como herramienta experimental de apoyo.

Estos resultados complementan la evaluación técnica del dispositivo al incorporar la perspectiva del usuario, permitiendo identificar fortalezas relacionadas con la experiencia de interacción y oportunidades de mejora asociadas con la claridad del procedimiento y acompañamiento durante el uso.
