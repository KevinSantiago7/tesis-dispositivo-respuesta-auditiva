# ANEXO A. REVISIÓN ESTRUCTURADA DE LITERATURA BAJO LINEAMIENTOS PRISMA 2020

## Versión final consolidada para GitHub

## A.1 Introducción

Se realizó una revisión estructurada de literatura para fundamentar el
desarrollo del dispositivo tecnológico propuesto, identificando avances
relacionados con evaluación auditiva infantil, respuestas conductuales
frente a estímulos sonoros, visión por computador y aprendizaje
automático.

El proceso tomó como referencia PRISMA 2020. Debido al volumen
documental recuperado, se aplicó una estrategia de dos fases:
priorización automatizada por concordancia temática y verificación
manual de los registros con mayor relevancia.

## A.7 Síntesis del estado del arte

Los estudios seleccionados se organizaron en cuatro líneas:

1.  Evaluación auditiva infantil y dispositivos tecnológicos.
2.  Respuestas conductuales frente a estímulos sonoros.
3.  Visión computacional aplicada al análisis infantil.
4.  Aprendizaje automático para clasificación de patrones observables.

## A.8 Brecha tecnológica

La literatura evidencia avances individuales en tamizaje auditivo,
análisis de movimiento infantil, visión computacional y modelos de
inteligencia artificial.

Sin embargo, existe una oportunidad de integración entre:

-   generación controlada de estímulos sonoros;
-   captura audiovisual del comportamiento infantil;
-   extracción automática de características;
-   clasificación mediante aprendizaje automático;
-   almacenamiento estructurado de ensayos;
-   revisión profesional posterior.

Esta integración constituye el aporte tecnológico del dispositivo
desarrollado.
